Why Workjet exists.

Claude already knows how to delegate. Workjet makes the handoff repeatable when workers span models, harnesses, accounts, skills, and computers. The coordination stays simple: send a complete brief, continue working, then verify the returned artifact.

  1. 01

    Install the contract

    Workjet maintains one marked include in the global Claude prompt. Fresh Claude Code and Claude Desktop sessions can read the declared worker roles.

  2. 02

    Let Claude select

    Claude plans the work and chooses one declared worker. Workjet does not invent a workflow or become a second orchestrator.

  3. 03

    Resolve and execute

    Workjet binds the chosen role to its configured harness, model, and local or remote computer, then starts a fire-and-forget run.

  4. 04

    Review independently

    Telemetry and a non-authoritative completion receipt return to Claude. Claude still inspects changes and reruns the required checks.

The app exposes configuration and observed state.

Authentic Workjet captures show computers, worker definitions, prompt ownership, health, and run evidence. Unknown and unavailable states stay explicit.

Transport the repository snapshot, not credentials.

For a configured remote target, Workjet sends an immutable Git bundle over a strictly host-key-verified SSH or Tailscale path. The remote computer needs no GitHub login, origin access, repository credential, or SSH agent forwarding.

  1. 01

    Verify the host

    Unknown or changed SSH host keys block setup.

  2. 02

    Send a fixed snapshot

    Tracked edits, deletions, and allowed untracked files travel as a capped raw Git bundle.

  3. 03

    Run in detached space

    The host creates one owned worktree and performs no network Git operation.

  4. 04

    Import a review ref

    Import writes only refs/workjet/<run-id>. It does not merge, move HEAD, stage files, or touch the active worktree.

Build from source today.

A public notarized release is not available. Source installation builds a local ad-hoc-signed macOS app and requires the Xcode command line tools plus rsvg-convert from librsvg.

Source install
git clone https://github.com/metric-space-ai/claude-workjet /tmp/claude-workjet
cd /tmp/claude-workjet
brew install librsvg
./install.sh

Verified boundary

Control host: macOS 14 or newer on Apple Silicon. Coding harnesses: Claude Code, Codex CLI, and OpenCode. Targets: the local Mac and configured remote Linux computers.

The installer preserves unrelated global Claude content and does not change project-local prompt files.
