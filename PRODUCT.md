# Product

## Register

product

## Users

Developers who enter through Claude Code or the Claude desktop app and use Workjet as a compact control surface for agentic work. They need to configure workers, models, providers, computers and telemetry quickly without learning internal implementation details.

## Product Purpose

Workjet is a minimal macOS menu-bar companion for a global Claude system-prompt extension and its configured coding-agent workers. It keeps local and remote computers, harnesses, model access and the generated orchestrator prompt synchronized and visibly healthy. Claude Fable remains the orchestrator; no opt-in command is required.

## Brand Personality

Mechanical, concentrated, decisive. The brand should feel like a turbine that draws in heterogeneous work, compresses it and releases focused execution.

## Anti-references

No generic AI sparkles, paper planes, chat bubbles, lettermarks, funnels disguised as turbines or decorative technical diagrams. No crowded SaaS dashboards, unexplained implementation language, excessive icons, dropdowns for primary computer switching or ornamental visual noise.

## Design Principles

1. Show the smallest useful amount of information first.
2. Make every configuration path direct and reversible.
3. Distinguish real measurements from unknown or unavailable data.
4. Keep generated behavior visible and editable at its actual source.
5. Express power through mechanical clarity, not decoration.

## Accessibility & Inclusion

Primary actions and status must remain understandable without color alone. Controls need descriptive accessibility labels and keyboard support. The Workjet mark must remain recognizable as a turbine in a monochrome 16-pixel macOS menu-bar rendering.
